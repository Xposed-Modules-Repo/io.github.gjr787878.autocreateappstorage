# AutoCreateAppStorage

**English:** Automatically creates missing private storage directories (Android/data/<package>) for apps on custom ROMs, fixing the false "insufficient storage" error when apps try to access their own data directory. One tap to detect all third-party apps and create missing directories.

**中文：** 自动补全应用缺失的私有存储目录（Android/data/<包名>），修复自定义 ROM 下 APP 误报"存储空间不足"的问题。一键检测所有第三方应用，自动补建缺失的目录，无需手动操作。

**Русский:** Автоматически создаёт отсутствующие приватные директории (Android/data/<пакет>) для приложений на кастомных прошивках, исправляя ошибку "недостаточно места". Одно нажатие — модуль проверит все сторонние приложения и создаст недостающие папки.
